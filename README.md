### 📡 SYSTEM OVERVIEW
A high-performance, dark-themed Flask application engineered to parse, identify, and locate Saudi Arabian phone numbers. Built for speed and accuracy, this tool extracts deep metadata directly to a responsive UI.

* **[ 01 ] Caller ID Routing:** Instant name resolution via integrated API.
* **[ 02 ] Network Forensics:** Carrier detection mapping (STC, Mobily, Zain).
* **[ 03 ] Geolocation:** Regional tracking for registered mobile assets.
* **[ 04 ] Input Validation:** Strict 9-digit format enforcement to prevent data corruption.
